# NEXORA Notification Navigation + Project Chat Update

- User notifications are now actionable buttons.
- Service/project notifications open NEXORA Services and automatically open the referenced project chat.
- Payment notifications open Transactions.
- Wallet/transfer notifications open Wallet or Send Money when applicable.
- Withdrawal notifications open Wallet.
- Membership notifications open Earn/Referrals.
- Support notifications open Help & Support.
- Marketplace notifications open Marketplace.
- Account notifications can open Profile & Security when a status is supplied.
- Notification items are marked read when opened.
- Activity Center notification items use the same routing.
- The member project-chat composer is now a large multi-line textarea with a visible bordered container, focus state, Send Message button, and Ctrl/Cmd+Enter shortcut.
- Mobile project chat stacks the composer controls for easier typing.
